# PERA — digital menu

Trilingual (Français / English / العربية) menu for PERA, 2 Descente du Marché, Vieux Nice.

Live: https://nassim078.github.io/pera-menu/ · Printable QR code: https://nassim078.github.io/pera-menu/qr/

## Update a price or a dish

1. Edit `src/menu_data.py`
2. Run `pip install segno && python3 src/build.py`
3. Commit and push — GitHub Pages republishes in about a minute. The QR code never changes.
